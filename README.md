## What is this?

7A Life Quest is a personal gamification app that transforms the **7A Framework** — a seven-domain life design for an eight-year "Second Calling" (2026–2034) — into seven interconnected games, built on the game design principles of Jane McGonigal's *Reality Is Broken*: clear **Goals**, meaningful **Rules**, instant **Feedback**, and **Voluntary Participation**.

Every tap earns XP. All seven quests feed one shared hero level — from 七域見習者 (Apprentice of Seven Realms) to the legendary 傳說 · 第二使命 (Second Calling) at 30,000 XP.

## Features

- **Hub screen** — all seven quests at a glance, with a shared hero level bar
- **Streak fires & lamps** — habit-science milestones (7 / 21 / 66 / 100 days)
- **Achievement badges** — 60+ unlockable honours across the realms
- **Observation journal (A3)** — dated notes of growth and growing edges for two beloved sons
- **Offer scroll (A4)** — a built-in Grand Slam Offer and cold-outreach scripts (Hormozi-style)
- **Data vault** — one-tap JSON export/import for weekly backups
- **Mobile-first** — designed to live on your phone's home screen

## Install on Your Phone (recommended)

Data is stored in the browser that opens the app, so always enter through the same door:

**iPhone (Safari):** open the [live app](https://ambrosecheng-bot.github.io/7A-games/) → Share button → **Add to Home Screen** → open only from that icon thereafter.

**Android (Chrome):** open the live app → ⋮ menu → **Add to Home screen / Install app**.

> ⚠️ Do not clear browsing/site data, and avoid private/incognito mode — both will erase your records. Home-screen installation also protects iPhone users from Safari's 7-day storage eviction policy.

## Backup & Restore

1. Hub → **資料保管庫 (Data Vault)** → **⬇️ 匯出備份 (Export Backup)** — downloads a dated JSON file
2. Move the file to Google Drive / Dropbox (a Friday weekly ritual is recommended)
3. To restore on any device: **⬆️ 匯入備份 (Import Backup)** → select your latest JSON — all seven realms return instantly
